# Workspace Instructions & Memory

## UI & Design Guidelines

### Absolute Constraint: No Emojis or Emoji Icons
- **Never use icons or emojis anywhere in the user interface or codebase.**
- Avoid all emojis in button texts, card headers, section titles, badge pills, alerts, spotlights, and navigation.
- All titles, badges, and buttons must be strictly professional, elegant, and text-only (e.g. "ترمیم کریں", "کلاس تبدیل کریں", "داخلہ محفوظ کریں", "طالب علم (لڑکا)").
- Retain the professional, executive layout, typography, and dark/light mode contrast without decorating with emojis.
